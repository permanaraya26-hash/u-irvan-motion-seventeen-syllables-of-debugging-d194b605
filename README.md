A [make.fun](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) bounty entry: a program that writes one haiku about debugging to `/output/entry.txt`.

## Run

```sh
node main.ts
```

It writes the haiku to `/output/entry.txt`. No dependencies, no network, deterministic — every run produces the same bytes.

## The haiku

> breakpoint holds its breath
> the loop still runs past midnight
> one stray character
